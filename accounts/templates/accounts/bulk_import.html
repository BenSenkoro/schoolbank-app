Tips for preparing your Excel file
• Use underscore for usernames e.g. john_doe not john doe
• Set one default password for all users e.g. mbonea2025 — they can change it later
• Role must be in lowercase e.g. student not Student
• Delete any extra sheets — only the first sheet is read
• Opening balance must be a plain number e.g. 50000 not 50,000
